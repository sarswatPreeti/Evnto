# Quick Start: Create Web3 Hackathon Event

## ⚡ Quick Steps

1. **Connect Wallet** → MetaMask on Monad Testnet
2. **Get MON** → [Monad Faucet](https://testnet.monad.xyz)
3. **Navigate** → `/event/create` page
4. **Fill Form** → Complete all required fields
5. **Submit** → Click "Create Event"

## 📝 Required Fields

| Field | Example | Notes |
|-------|---------|-------|
| **Title** | "Monad Web3 Hackathon" | Catchy name |
| **Description** | "48hr hackathon..." | Include details |
| **Category** | Web3 Hacks | Default |
| **Date** | 2025-12-15 | Future date |
| **Time** | 09:00 | Start time |
| **Location** | "Tech Hub, SF" | Physical/Virtual |
| **Join Fee** | 0.00001 MON | Default fee |
| **Seats** | 250 | Max participants |

## 💰 Fee Structure

- **Default Join Fee**: `0.00001 MON`
- **Minimum**: `0.00001 MON`
