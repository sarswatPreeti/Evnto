# Evnto — Decentralized Event Ticketing & Participation Platform (Monad Testnet)

Evnto is a decentralized event management and ticketing platform built on the **Monad Testnet**. It enables users to **discover, create, and participate** in events while ensuring transparency, security, and true ownership of tickets.

By combining familiar event workflows with **blockchain-based verification** and **automated NFT ticketing**, Evnto brings a new level of trust and accessibility for both organizers and attendees.

---

## 🌐 Key Features

### 1. Blockchain-Secured Ticketing on Monad
All tickets are minted as **NFTs** on the Monad testnet, ensuring:
- Verifiable and tamper-proof ownership  
- Prevention of duplicate or fake tickets  
- Custom ticket rules (transferable or soulbound)

---

### 2. Multi-Category Event Support
Evnto supports multiple event types:
- Web3 Hackathons  
- Live Music & Entertainment Shows  

This helps organizers reach diverse audiences across industries.

---

### 3. Wallet-Optional Onboarding
To make onboarding smoother for Web2 users:
- Supports **Passkey or Email login**
- **Gas-sponsored interactions** using meta-transactions  
- Users can upgrade to **self-custody** by connecting a wallet  

This offers a Web2-like experience with Web3 benefits.

---

### 4. Automated Smart Contract Revenue Management
Ticket payments and organizer payouts are handled **automatically via smart contracts**, enabling:
- No intermediaries or hidden fees  
- Transparent revenue distribution  
- Real-time tracking and analytics  

---

### 5. Proof of Participation NFT Rewards
Attendees receive **non-transferable NFT badges** for participation, serving as:
- Digital collectibles or souvenirs  
- Proof of attendance  
- Reputation builders that can unlock future perks  

---

### 6. Fan & Contributor Priority System
To reward loyal users:
- **Hackathons** can prioritize users based on GitHub contributions  
- **Concerts** can prioritize fans via Spotify listening history  

This adds fairness and loyalty-based access beyond payments.

---

### 7. Anti-Scalping & Anti-Bot Controls
Organizers can configure:
- Mint limits per user  
- Time-based claim windows  
- On-chain eligibility checks  

Ensures tickets go to **real fans and participants**, not bots.

---

## ⚙️ Technology Stack

| Layer | Technology |
|-------|-------------|
| Blockchain | Monad Testnet (EVM Compatible) |
| Smart Contracts | Solidity (NFT + Meta-Transactions) |
| Web App | Next.js + React + TypeScript |
| Wallets | EVM Wallets + Passkey/Email Onboarding |
| Backend | Node.js + Custom Auth Layer |
| APIs | GitHub & Spotify (for user validation) |

---

## 🧩 Architecture Overview
Evnto follows a **modular and decentralized architecture** featuring:
- Gas Relayer / Paymaster for sponsored transactions  
- Smart contract–based ticket minting and transfers  
- Role-based access (organizer, participant, admin)  
- Off-chain eligibility evaluation + on-chain proof  
- Decentralized metadata storage (IPFS planned for mainnet phase)  

---

## 🚀 Vision
Evnto aims to transform event ticketing by:
- Eliminating fraud and scalping  
- Empowering organizers, artists, and communities directly  
- Making loyalty and reputation meaningful across ecosystems  
- Seamlessly onboarding new users into Web3  

As Monad moves to mainnet, Evnto will evolve into a **high-performance platform** capable of serving millions with low gas fees and ecosystem integrations.
